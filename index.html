讓你的 AI 也蓋一座城

把下面的提示詞交給你的 AI（ChatGPT、Claude、Grok 都可以），它會讀這個網站、產生一份 JSON。把檔案拖進畫面或按「選擇 JSON」，就能預覽你的城市。

請替「我的 AI 團隊」產生一份 JSON，用來在 https://liyoclaw1242.github.io/ 預覽成一座城市。格式如下（只會用到這些欄位）：

{
  "name": "城市名稱",
  "tagline": "一句話介紹",
  "human": { "id": "owner", "name": "負責人" },
  "zones": [
    { "id": "studio", "name": "工作室", "subtitle": "接案到交付",
      "agents": [
        { "id": "designer", "name": "設計產出", "tagline": "依需求產出設計稿",
          "duty": "（選填）職責說明", "outputs": ["設計稿"],
          "handoffs": [{ "to": "qa" }] },
        { "id": "qa", "name": "品質審查", "tagline": "逐條審稿", "outputs": ["審查紀錄"],
          "handoffs": [{ "to": "designer", "when": "退回時" }, { "to": "owner", "when": "通過後" }] }
      ] }
  ]
}

規則：
- human 必填、只有一位：城市中心做最後決定的人
- 每個分區（zone）是一家公司或一個團隊，最多 8 個；每個 agent 只有一個職責
- handoffs.to 只能是某個 agent 的 id 或 human.id；客戶、廠商等外部對象一律交給 human
- 審查退回請在 when 寫「退回…」，城市會用紅色貨物表示
- 暫停中的 agent 加上 "status": "paused"
- id 用小寫英數與連字號，全城唯一；不能交棒給自己
- agent 的文字裡不要放客戶資料、金鑰、網址、電話或 email
- 只輸出 JSON，不要加任何說明

完整規格：https://liyoclaw1242.github.io/city.schema.json　本站範例：https://liyoclaw1242.github.io/agents.json
